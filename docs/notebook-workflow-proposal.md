# Notebook Workflow Proposal

## Problem
Claude training suggests strong notebook support, but in practice the workflow is not yet clear or smooth enough for ML tasks.

## Goal
Define a practical notebook-based workflow for ML/AI work in Claude.

## First scope
- Inspect notebook-related capabilities
- Define recommended notebook workflow
- Add prompt examples
- Document current limitations and best practices

## Out of scope
- Full ML platform support
- Model training framework
- Experiment tracking integrations
